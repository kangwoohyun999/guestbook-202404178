# 계정 없이 글 비밀번호로 소유권을 확인한다

회원가입·로그인 없이, 방명록 글마다 작성 시 정한 글 비밀번호(scrypt 해시로 저장)를 대조해 수정·삭제 자격을 판단한다. 방명록은 익명으로 가볍게 남기는 곳이라 계정은 과하고, 관리자 기능도 범위 밖이므로 글 비밀번호가 유일한 권한 수단이다.

## Consequences

- 글 비밀번호를 잊으면 그 글은 누구도 고치거나 지울 수 없다.
- 비밀번호 시도 횟수 제한은 두지 않는다. 짧은 비밀번호는 무차별 대입에 약하다는 것을 알고 받아들인 한계이며, 느린 해시(scrypt)가 유일한 완화책이다.
- DB 접근은 ORM 없이 `@neondatabase/serverless`로 raw SQL을 쓴다(과제 요구사항). 테이블이 하나뿐이라 ORM이 줄여 줄 것이 없다.
